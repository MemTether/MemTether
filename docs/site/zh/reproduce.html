复现 MemTether

100% 可复现 Apache-2.0 欢迎独立运行验证

别信我们说的数字，自己跑一遍。本页每个结论背后都有一条可执行的命令。

1. 环境

# Python 3.10 或 3.12
python --version

# 创建干净的虚拟环境
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate   # Windows

# 安装
pip install memtether

2. 冒烟测试

# 初始化 + 验证 23 个适配器
memtether init

# 写一条记忆
memtether remember "复现测试内容" --source reproduce

# 搜索它
memtether search "复现测试" --list

# 预期输出: [fact/reproduce] 复现测试内容

3. 跑测试套件

git clone https://github.com/MemTether/MemTether.git
cd MemTether
pip install -e ".[server]"

# 运行全部测试
pytest tests/ -v --tb=short

# 预期: 461 passed, 4 skipped（a61 起口径）

4. 覆盖率

pip install pytest-cov
pytest tests/ --cov=. --cov-report=term

# 预期: TOTAL ~55%（461 测试口径）
# 明细: memory_court 98% / predicates 95% / consolidation 67%
#       governance 57% / memsearch ~57% / gateway 54% / tether_connect 49%

5. LongMemEval 基准

MemTether 在 LongMemEval 500 题全量运行中报告 strict-match 62.6%（334 题适用）。EAF 模式把多会话 strict 从 32.5% 提升到 60.0%（配对 p=0.008，n=131）。

可复现性声明：基准测试工具在私有生产实例中。我们正在准备公开的基准工件包（目标 2026-12）。在此之前，这些数字是声明值，未经独立复现。

参考：LongMemEval 论文 · 官方仓库
