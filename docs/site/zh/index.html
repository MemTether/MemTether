MemTether

跨客户端 AI 记忆中枢。一份物理 SQLite。多个 Agent。文件级指针。零云端。

Apache-2.0 23 个适配器 461 项测试 本地优先 双时间轴

快速开始

pip install memtether
memtether init

就这么简单。MemTether 会自动检测你机器上的 23 种 AI 客户端，写入 MCP 配置并验证。

为什么做 MemTether

你的 AI 编程助手每次会话结束就失忆。mem0/Hindsight 给你的是云端 API；腾讯云方案要装 Node.js + WSL2 + 8GB 内存。MemTether 的答案是一份 SQLite 文件，用操作系统级的 junction/symlink 共享——没有守护进程、没有云、没有同步逻辑。
