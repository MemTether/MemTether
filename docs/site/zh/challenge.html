创始 10 人计划

10 个名额 14 天诚实结果

不是来捧场的——来拆台的，或者证明我们是对的。

前 10 位在自己的真实 AI 编程环境里运行 MemTether，并提交 14 天诚实报告的人，将获得创始贡献者身份：README 署名、功能请求优先处理、与维护者的直接沟通渠道。

你要做什么

  1. 原样运行 —— pip install memtether && memtether init，不做任何定制配置。
  2. 用满 14 天 —— 真实工作、真实 agent、真实会话。
  3. 找出不能信任的地方 —— 崩溃、记忆错误、适配器失败，什么都行。
  4. 提交任意诚实结果 —— 好评、差评或混合评价，三种都算数。

我们会公开什么

每一份提交（无论好坏）都会在 README 中署名公开。发现真 bug 的人以「发现者」署名；一切正常的人以「验证者」署名。

我们不挑选好评。诚实的失败比表扬更有价值——它告诉我们该修什么。

如何报名

到 MemTether Issues 开一个 issue，标题格式 [Founding 10] <轨道>，附上你的操作系统 / Python / AI 客户端 / 开始日期。我们 24 小时内确认。

规则

  • 从你的开始日期算 14 天，不延期。
  • 通过 GitHub issue（公开）提交——诚实就是全部意义。
  • 10 个名额须在本页上线后 60 天内完成，否则挑战重置。
  • 创始贡献者获得 README 署名 + issue 优先处理。没有报酬，没有股权。
  • 维护者保留拒绝非真实使用的权利。
