MemTether

Cross-client AI memory hub. One physical SQLite. Many agents. File-level pointers. Zero cloud.

Apache-2.0 23 adapters 100 tests Local-first Bi-temporal

Quick start

pip install memtether
memtether init

That's it. MemTether detects 23 AI clients on your machine, writes MCP config, and verifies.

Why MemTether

Your AI coding agents forget everything between sessions. mem0/Hindsight give you a cloud API. TencentDB needs Node.js + WSL2 + 8GB RAM. MemTether gives you one SQLite file shared via OS-level symlinks - no daemon, no cloud, no sync logic.
