Reproduce MemTether

100% reproducible Apache-2.0 Independent runs welcome

Don't trust the numbers. Run them yourself. Every claim on this page has a reproducible command behind it.

1. Environment

# Python 3.10 or 3.12
python --version

# Create clean venv
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate   # Windows

# Install
pip install memtether

2. Smoke test

# Initialize + verify 23 adapters detected
memtether init

# Write a memory
memtether remember "Test content for reproduction" --source reproduce

# Search it back
memtether search "Test content" --list

# Expected: [fact/reproduce] Test content for reproduction

3. Run the test suite

git clone https://github.com/MemTether/MemTether.git
cd MemTether
pip install -e ".[server]"

# Run 100 tests
pytest tests/ -v --tb=short

# Expected: 100 passed (or 100 passed, 1 warning)

4. Coverage

pip install pytest-cov
pytest tests/ --cov=. --cov-report=term

# Expected: TOTAL ~26% (100 tests)
# Breakdown: hubguard 61% / memsearch 47% / gateway 24% / governance 21%

5. LongMemEval benchmark

MemTether reports strict-match 62.6% (209/334 applicable) on LongMemEval 500Q full run. EAF mode lifts multi-session strict from 32.5% to 60.0% (paired p=0.008, n=131).

Reproducibility status: benchmark harness is in the private production instance. We are actively preparing a public benchmark artifact bundle with fixture digests (target: 2026-12). Until then, the numbers are declared, not independently reproduced.

Reference: LongMemEval paper · official repo

7. File integrity

All releases publish wheel + tar.gz with SHA-256 digests on the GitHub Release page. Verify with:

sha256sum memtether-0.1.0a31-py3-none-any.whl

Compare against the digest in the release notes.

8. Independent reproduction

If you reproduce (or fail to reproduce) any claim, open an issue at MemTether issues with:

  • Your environment (OS / Python / versions)
  • Command you ran
  • Expected vs actual output
  • Raw artifact (JSON/text) if possible

Submissions are reviewed and attributed. Honest negative results are welcome.
