## How to contribute

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full guide. In short:

1. Fork, branch, implement with tests (`pytest tests/ -q` must pass).
2. Run `python scripts/check_packaging.py` before submitting.
3. Open a PR describing what changed and why.

First-time contributors: look for issues labelled `good first issue`.
