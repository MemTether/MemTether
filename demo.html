Key Differentiators vs Competitors

  • File-level pointers — multiple AI clients share ONE physical SQLite file (not copies)
  • Dual-timeline — query "what was true at any point in time" (T / T' axes)
  • Supersession chain — old facts preserved, never deleted, full audit trail
  • Q-Value auto-bump — retrieval-triggered relevance scoring with time decay
  • Coverage-first packet compiler — ensures diverse, complete evidence packets
  • Deterministic scaffolds — counting/temporal/comparison rules before LLM
  • Local embedding — bge-m3 int8, works offline, no API keys needed
  • 100% auditable — every retrieval result has reason codes for each scoring factor
